# Accessi-download 無障礙基準

本文件是 Accessi-download 的 NVDA / 鍵盤操作基準。後續 UI 修改應避免破壞這些行為。

## 設計原則

1. 優先使用 WinForms 原生控制項，不用自繪按鈕、假下拉選單或只靠滑鼠操作的元件。
2. 所有可操作控制項都必須能以 `Tab` / `Shift+Tab` 到達。
3. 每個輸入框、下拉選單、按鈕都需要清楚且不重複的 Accessible Name。
4. 不用顏色作為唯一狀態提示。
5. 解析、下載、取消、更新等狀態必須同時以文字呈現。
6. 錯誤不能只寫在 log；需要有可由螢幕閱讀器讀到的訊息方塊。
7. 不自動把焦點搶離使用者目前操作位置，除非是必須處理的錯誤或確認對話框。

## NVDA 驗收項目

### 下載分頁

- 啟動後可使用 Tab 找到：
  - 影片網址
  - 解析影片資訊
  - 影片 / 只下載音訊
  - 影片畫質
  - 影片輸出格式
  - 來源音訊品質
  - 音訊輸出格式
  - 音訊輸出品質
  - 下載後儲存位置
  - 選擇下載資料夾
  - 開始下載
  - 取消目前操作
  - 開啟下載資料夾
  - 下載進度
  - 狀態
- 選擇「影片」時，音訊專用欄位不可操作。
- 選擇「只下載音訊」時，影片專用欄位不可操作。
- 解析完成後，NVDA 能讀到影片標題、上傳者與長度。
- 畫質下拉選單只出現該影片解析到的實際高度。
- 音訊來源下拉選單會列出可辨識的來源位元率與格式。
- 下載時狀態文字持續更新百分比、速度與 ETA（有資料時）。
- 按 Esc 或「取消」可以中止目前 yt-dlp / FFmpeg 子程序。

### 登入與更新分頁

- Cookie 來源下拉選單可用鍵盤完整操作。
- 只有選擇 `cookies.txt` 時，Cookie 路徑與選檔按鈕才會啟用。
- YouTube / Bilibili 登入按鈕使用預設瀏覽器開啟網頁。
- 程式不提供帳號或密碼輸入框。
- yt-dlp 版本文字可被 NVDA 讀取。
- 更新頻道可選 Stable / Nightly / Master。
- 啟動更新提示預設關閉，由使用者自行決定是否啟用。
- 「檢查必要元件」能明確指出缺少的是 yt-dlp、FFmpeg、FFprobe 或 Deno。

### 記錄分頁

- Log 為唯讀文字框，可使用 NVDA 逐行閱讀及 Ctrl+A / Ctrl+C 複製。
- 提供「複製全部」與「清除記錄」按鈕。

## 鍵盤基準

- `F5`：解析目前網址。
- `Esc`：取消目前操作。
- 主要操作按鈕保留 Alt mnemonic。
- 對話框按鈕遵守 Windows 標準 Yes / No / OK 鍵盤行為。

## 不應出現的回歸

- 只靠滑鼠 hover 才出現的主要操作。
- 沒有文字名稱的「按鈕」。
- Tab 焦點卡在不可見 / 不可操作元件。
- 下載狀態只顯示進度條、沒有文字。
- 自動更新 yt-dlp 而完全不讓使用者決定。
- 在程式內要求輸入 YouTube / Bilibili 帳號密碼。
