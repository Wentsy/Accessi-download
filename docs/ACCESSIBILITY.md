# Accessi-download 無障礙基準

本文件是 Accessi-download 的 NVDA / 鍵盤操作基準。後續 UI 修改應避免破壞這些行為。

## 設計原則

1. 優先使用 WinForms 原生控制項，不用自繪按鈕、假下拉選單或只靠滑鼠操作的元件。
2. 所有可操作控制項都必須能以 `Tab` / `Shift+Tab` 到達。
3. 每個輸入框、下拉選單、核取方塊、按鈕都需要清楚且不重複的 Accessible Name。
4. 不用顏色作為唯一狀態提示。
5. 解析、下載、取消、更新等狀態必須同時以文字呈現。
6. 錯誤不能只寫在 log；需要有可由螢幕閱讀器讀到的訊息方塊。
7. 不自動把焦點搶離使用者目前操作位置，除非是必須處理的錯誤或確認對話框。
8. 可持續保存的使用者偏好應使用標準核取方塊／下拉選單呈現，不用每次下載後重複跳確認對話框。

## NVDA 驗收項目

### 下載分頁

啟動後可使用 Tab 找到：

- 多行網址輸入框，NVDA 朗讀為可一行一個網址。
- 解析第一個網址。
- 是否下載整個播放清單／合集。
- 影片 / 只下載音訊。
- 影片畫質。
- 影片輸出格式。
- 來源音訊品質。
- 音訊輸出格式。
- 音訊輸出品質。
- 是否在檔名加入影片 ID。
- 是否在下載完成後自動開啟資料夾。
- 下載後儲存位置。
- 選擇下載資料夾。
- 開始下載。
- 取消目前操作。
- 開啟下載資料夾。
- 下載進度。
- 狀態。

行為基準：

- 選擇「影片」時，音訊專用欄位不可操作。
- 選擇「只下載音訊」時，影片專用欄位不可操作。
- 解析完成後，NVDA 能讀到第一個網址的影片標題、上傳者與長度。
- 多行網址時，解析狀態會告知偵測到的網址數量。
- 畫質下拉選單只出現第一個解析影片實際取得的高度；批量下載時相同限制套用到各項目。
- 音訊來源下拉選單會列出第一個影片可辨識的來源位元率與格式；批量或播放清單下載時改由每個項目自動選最佳來源，避免套用錯誤的 format ID。
- 「下載整個播放清單／合集」預設未勾選；勾選後會建立以播放清單／合集名稱命名的資料夾，並在項目前加入清單順序。
- 「檔名加入影片 ID」預設未勾選；勾選後檔名可包含例如 `[BV1rHYx6fEzy]` 的來源 ID。
- 「下載完成後自動開啟資料夾」預設未勾選。
- 下載完成後不應再跳出 Yes / No 的「是否開啟資料夾」對話框。
- 若使用者勾選自動開啟，下載完成後才開啟輸出資料夾；播放清單時優先開啟實際的播放清單資料夾。
- 下載時狀態文字持續更新目前項目名稱、百分比、速度與 ETA（有資料時）。
- 按 Esc 或「取消」可以中止目前 yt-dlp / FFmpeg 子程序。

### 偏好保存

以下項目修改後應自動保存至 portable 資料夾旁的 `settings.ini`，重新啟動後恢復：

- 下載位置。
- 影片 / 音訊模式。
- 影片畫質與輸出格式。
- 音訊輸出格式與輸出音質。
- 是否下載播放清單／合集。
- 是否加入影片 ID。
- 是否完成後自動開啟資料夾。
- Cookie 來源。
- yt-dlp 更新頻道與啟動更新提示。

設定檔寫入失敗（例如程式位於唯讀資料夾）不得阻止程式啟動或下載。

### 登入與更新分頁

- Cookie 來源下拉選單可用鍵盤完整操作。
- 只有選擇 `cookies.txt` 時，Cookie 路徑與選檔按鈕才會啟用。
- YouTube / Bilibili 登入按鈕使用預設瀏覽器開啟網頁。
- 程式不提供帳號或密碼輸入框。
- yt-dlp 版本文字可被 NVDA 讀取。
- 更新頻道可選 Stable / Nightly / Master。
- 啟動更新提示預設關閉，由使用者自行決定是否啟用。
- 「檢查必要元件」能明確指出缺少的是 yt-dlp、FFmpeg、FFprobe 或 Deno。

### 記錄分頁

- Log 為唯讀文字框，可使用 NVDA 逐行閱讀及 Ctrl+A / Ctrl+C 複製。
- 提供「複製全部」與「清除記錄」按鈕。
- 批量／播放清單下載時，每個完成檔案都應出現在記錄中。

## 鍵盤基準

- `F5`：解析第一個網址。
- `Esc`：取消目前操作。
- 主要操作按鈕保留 Alt mnemonic。
- 必要的訊息方塊遵守 Windows 標準按鈕鍵盤行為。

## 不應出現的回歸

- 只靠滑鼠 hover 才出現的主要操作。
- 沒有文字名稱的「按鈕」。
- Tab 焦點卡在不可見 / 不可操作元件。
- 下載狀態只顯示進度條、沒有文字。
- 每次下載完成都強迫跳出是否開啟資料夾的確認框。
- 單支影片網址因帶有 `list=` 就在預設狀態下載整份播放清單。
- 使用者關閉影片 ID 選項後，檔名仍固定包含 ID。
- 偏好修改後重新啟動全部被重設。
- 自動更新 yt-dlp 而完全不讓使用者決定。
- 在程式內要求輸入 YouTube / Bilibili 帳號密碼。
