# Accessi-download 無障礙基準

本文件是 Accessi-download 的 NVDA / 鍵盤操作基準。後續 UI 修改應避免破壞這些行為。

目前穩定基準：**v0.2.17**。

## 設計原則

1. 優先使用 WinForms 原生控制項，不用自繪按鈕、假下拉選單或只靠滑鼠操作的元件。
2. 所有可操作控制項都必須能以 `Tab` / `Shift+Tab` 到達。
3. 每個輸入框、下拉選單、核取方塊、按鈕都需要清楚且不重複的 Accessible Name。
4. 不用顏色作為唯一狀態提示。
5. 下載、取消、更新等狀態必須同時以文字呈現。
6. 錯誤不能只寫在 log；需要有可由螢幕閱讀器讀到的訊息方塊。
7. 不自動把焦點搶離使用者目前操作位置，除非是必須處理的錯誤或確認對話框。
8. 可持續保存的使用者偏好應使用標準核取方塊／下拉選單呈現，不用每次下載後重複跳確認對話框。
9. 主下載流程不要求先執行「取得影片資訊」之類的額外步驟；貼上網址後即可直接下載。

## NVDA 驗收項目

### 下載分頁

啟動後預設焦點直接停在多行網址輸入框，可立即貼上網址；再使用 Tab 可找到：

- 多行網址輸入框，NVDA 朗讀為可一行一個網址。
- 是否下載整個播放清單／合集。
- 影片 / 只下載音訊。
- 影片畫質上限。
- 影片輸出格式。
- 音訊輸出格式。
- 音訊輸出品質。
- 是否在檔名加入影片 ID。
- 是否在下載完成後自動開啟資料夾。
- 下載後儲存位置。
- 選擇下載資料夾。
- 開始下載。
- 取消目前操作。
- 開啟下載資料夾。
- 下載進度。
- 狀態。

行為基準：

- 貼上網址後可直接按「開始下載」，不需先取得影片資訊。
- 選擇「影片」時，音訊專用欄位不可操作。
- 選擇「只下載音訊」時，影片專用欄位不可操作。
- 畫質下拉選單提供常用上限；yt-dlp 在上限內自動選擇最佳可用來源。
- 音訊來源由 yt-dlp 自動選擇最佳可用來源，不另外要求使用者選 format ID。
- 「下載整個播放清單／合集」預設未勾選；勾選後會建立以播放清單／合集名稱命名的資料夾，並在項目前加入清單順序。
- 「檔名加入影片 ID」預設未勾選；勾選後檔名可包含例如 `[BV1rHYx6fEzy]` 的來源 ID。
- 「下載完成後自動開啟資料夾」預設未勾選。
- 下載完成後不應再跳出 Yes / No 的「是否開啟資料夾」對話框。
- 下載成功且 yt-dlp 回報至少一個完成檔案後，自動清空網址編輯區；不主動搶回焦點。
- 下載失敗或取消時，網址必須保留，方便直接重試。
- 若使用者勾選自動開啟，下載完成後才開啟輸出資料夾；播放清單時優先開啟實際的播放清單資料夾。
- 下載時狀態文字持續更新目前項目、百分比、速度與 ETA（有資料時）。
- NVDA 會在約每 10% 的里程碑朗讀下載進度；狀態區維持單一覆蓋式內容，不累積歷史訊息。
- 批量下載顯示第 N / 總 M 個項目；合集下載則以合集內項目總數計數。
- 按 Esc 或「取消」可以中止目前 yt-dlp / FFmpeg 子程序。

### 支援網站

- YouTube。
- Bilibili。
- Douyin 抖音單支影片網址、分享短網址與合集 / collection / mix 網址。
- 抖音採用專用 WebView2 網頁解析引擎，讓真正的抖音頁面自行產生目前所需的驗證 / 簽名，不依賴 yt-dlp 的抖音 extractor 或瀏覽器 cookies.txt。
- 抖音單支影片支援影片與只下載音訊。
- 抖音可一行一個網址進行批量下載。
- 勾選「下載整個播放清單／合集」後，抖音合集會自動取得完整作品清單，以合集名稱建立資料夾，再逐項下載。
- 抖音 WebView2 的瀏覽狀態保存在 portable 資料夾旁的 `browser-data/DouyinWebView2`，可跨次啟動沿用。
- 只有真的需要人工驗證時，才顯示抖音網頁驗證視窗。
- 其他 yt-dlp 可處理的網站仍可直接嘗試。

### 偏好保存

以下項目修改後應自動保存至 portable 資料夾旁的 `settings.ini`，重新啟動後恢復：

- 下載位置。
- 影片 / 音訊模式。
- 影片畫質與輸出格式。
- 音訊輸出格式與輸出音質。
- 是否下載播放清單／合集。
- 是否加入影片 ID。
- 是否完成後自動開啟資料夾。
- Cookie 來源。
- yt-dlp 更新頻道與啟動更新提示。

設定檔寫入失敗（例如程式位於唯讀資料夾）不得阻止程式啟動或下載。

### 登入與更新分頁

- Cookie 來源下拉選單可用鍵盤完整操作。
- 只有選擇 `cookies.txt` 時，Cookie 路徑與選檔按鈕才會啟用。
- YouTube / Bilibili / Douyin 按鈕使用預設瀏覽器開啟對應網站。
- 抖音下載本身不要求使用者先匯入瀏覽器 Cookie；Cookie 來源設定保留給其他 yt-dlp 網站使用。
- 程式不提供帳號或密碼輸入框。
- yt-dlp 版本文字可被 NVDA 讀取。
- 更新頻道可選 Stable / Nightly / Master。
- 啟動更新提示預設關閉，由使用者自行決定是否啟用。
- 「檢查必要元件」能明確指出缺少的是 yt-dlp、FFmpeg、FFprobe 或 Deno。

### 記錄分頁

- Log 為唯讀文字框，可使用 NVDA 逐行閱讀及 Ctrl+A / Ctrl+C 複製。
- 提供「複製全部」與「清除記錄」按鈕。
- 批量／播放清單下載時，每個完成檔案都應出現在記錄中。

## 鍵盤基準

- `Esc`：取消目前操作。
- 主要操作按鈕保留 Alt mnemonic。
- 必要的訊息方塊遵守 Windows 標準按鈕鍵盤行為。

## 不應出現的回歸

- 只靠滑鼠 hover 才出現的主要操作。
- 沒有文字名稱的「按鈕」。
- Tab 焦點卡在不可見 / 不可操作元件。
- 下載狀態只顯示進度條、沒有文字。
- 主流程重新加入「必須先取得影片資訊」的步驟。
- 下載成功後網址沒有清除，或失敗／取消時反而把網址清掉。
- 每次下載完成都強迫跳出是否開啟資料夾的確認框。
- 單支影片網址因帶有 `list=` 就在預設狀態下載整份播放清單。
- 使用者關閉影片 ID 選項後，檔名仍固定包含 ID。
- 偏好修改後重新啟動全部被重設。
- 自動更新 yt-dlp 而完全不讓使用者決定。
- 在程式內要求輸入 YouTube / Bilibili / Douyin 帳號密碼。
